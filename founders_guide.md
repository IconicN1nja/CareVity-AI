# CareVity AI - AWS Backend Deployment Guide

Welcome! This guide is for the founder or technical lead who will deploy the CareVity AI backend to their own paid AWS account. The mobile application code is already configured to connect to AWS; it just needs the cloud resources to be spun up.

We have provided an automated deployment script to make this as seamless as possible.

---

## Step 1: Prepare Your AWS Account

1. Go to [aws.amazon.com](https://aws.amazon.com/) and create a new account or log in to an existing one.
2. Complete the account setup (add a payment method and verify your identity). Note that AWS may take up to 24 hours to fully activate a new account.
3. Once activated, log into the AWS Management Console and search for **IAM** (Identity and Access Management).
4. Create a new IAM User:
   - Name: `amplify-admin`
   - Permissions: Select "Attach policies directly" and check **AdministratorAccess-Amplify**.
5. Once the user is created, click on it, go to the **Security credentials** tab, and generate an **Access Key**. Choose "Command Line Interface (CLI)" as the use case.
6. **Save the Access Key ID and Secret Access Key** shown on the screen.

---

## Step 2: Configure Your Local Environment

You need the AWS CLI and Node.js installed on your computer.

1. Install the AWS CLI and configure it by running this in your terminal:
   ```bash
   aws configure
   ```
   When prompted, enter your Access Key ID, Secret Access Key, your preferred region (e.g., `us-east-1`), and `json` as the default output format.

---

## Step 3: Run the Auto-Deploy Script (Recommended)

To make things easy, we created a PowerShell script that automates the Amplify initialization and Auth provisioning. 

1. Open PowerShell in the root of the `CareVity-AI-mvp` folder.
2. Run the script:
   ```powershell
   .\deploy-backend.ps1
   ```
3. The script will ask for your **OpenAI API Key** and automatically set up the Amplify backend and Cognito Authentication for you.

*(Note: If you prefer to do this manually instead of using the script, see the "Manual Deployment Alternative" section at the bottom of this page).*

---

## Step 4: Add the AI Serverless API (Lambda)

Once the script finishes, you just need to add the Lambda API that powers the AI coach. We have provided the complete code in `aws-backend-template/askAI-lambda.ts`.

1. In your terminal, run:
   ```bash
   amplify add api
   ```
2. Select **REST**.
3. Provide a friendly name (e.g., `carevityApi`).
4. Provide a path (e.g., `/askAI`).
5. Choose to **Create a new Lambda function**.
6. Provide a friendly name for the function (e.g., `askAILambda`).
7. Choose the runtime: **NodeJS**.
8. Choose the function template: **Hello World**.
9. Do you want to configure advanced settings? **Yes**.
10. Do you want to configure environment variables? **Yes**.
    - Key: `OPENAI_API_KEY`
    - Value: `sk-...` (Paste your actual OpenAI API Key here).
11. Do you want to edit the local lambda function now? **Yes**.
    - Open `amplify/backend/function/askAILambda/src/index.js` (or `.ts`).
    - **Replace all of its contents with the code found in `aws-backend-template/askAI-lambda.ts`.**
    - Save the file and return to the terminal to hit Enter.
12. Restrict API access? **No** (or configure as needed for production).

---

## Step 5: Add the Database (DynamoDB)

1. Run the storage command:
   ```bash
   amplify add storage
   ```
2. Select **NoSQL Database**.
3. Name the resource: `userScores`
4. Name the table: `UserScores`
5. What would you like to name this column? `userId` (Type: `string`)
6. Choose `userId` as the Partition Key.
7. Say **No** to adding a Sort Key or Global Secondary Indexes.

---

## Step 6: Deploy to AWS

1. Run the push command:
   ```bash
   amplify push --yes
   ```
   *This process takes a few minutes as AWS spins up the cloud resources.*

2. Once complete, Amplify will automatically generate a file called `aws-exports.js` in your source directory.

---

## Step 7: Configure Frontend Environment Variables

1. Copy the `.env.example` file to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Open the `aws-exports.js` file generated by Amplify.
3. Copy the relevant values (API Gateway endpoint URL, Cognito Pool IDs, etc.) from `aws-exports.js` and paste them into your new `.env` file.

---

## Step 8: Run the App

1. Install npm dependencies if you haven't already:
   ```bash
   npm install
   ```
2. Start the Expo server:
   ```bash
   npm start
   ```

You are now running CareVity AI with a fully functional, live AWS backend!

---

### Manual Deployment Alternative
If you prefer not to use `.\deploy-backend.ps1` in Step 3, you can do it manually:
1. `npm install -g @aws-amplify/cli`
2. `amplify init` (Answer defaults, choose your AWS profile)
3. `amplify add auth` (Select Default configuration, Email sign-in)
4. Proceed to Step 4 above.
